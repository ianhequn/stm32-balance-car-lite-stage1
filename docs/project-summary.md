# 项目阶段总结

## 目标

项目目标来自嵌入式组两轮平衡小车考核：基于 STM32 平台实现稳定平衡、运动控制、可视化输出和可扩展功能，并能讲清楚控制链路与工程设计。

第一阶段目标不是追求完美参数，而是完成一个最小可展示系统：

- 小车能够直立平衡
- 能通过编码器形成速度反馈
- 能通过蓝牙遥控运动
- 能通过 OLED 和串口观察状态
- 能加入超声波跟随/避障模式
- 能把代码、APK、视频整理成作品仓库

## Notion 学习链路

项目 Notion 页面按教程推进，大致分为这些阶段：

1. STM32CubeMX 工程生成
2. GPIO 与 LED
3. Timer 与按键消抖
4. USART 与 printf 重定向
5. Timer 编码器模式读取编码器
6. PWM 与 TB6612FNG 驱动电机
7. I2C 读取 MPU6050
8. 姿态解算与互补滤波
9. PID 原理
10. 角度环 PID
11. 速度外环 PID
12. 机械零点
13. 提起/着陆识别
14. 超声波测距、避障、跟随
15. U8g2/OLED 显示
16. 蓝牙遥控

## 教程外增强

在教程基础上额外做了：

- 蓝牙单字符协议固件解析
- Android 蓝牙遥控 APK
- OLED 显示蓝牙接收字符和计数
- 喵呜地面站多通道调试输出
- 超声波跟随逻辑平滑
- 提起保护与蓝牙命令兼容
- 代码与媒体资料归档

## 当前第一阶段结论

这个项目已经具备“小型嵌入式控制系统”的基本形态：

- 传感器：MPU6050、编码器、超声波、蓝牙
- 执行器：直流电机、TB6612FNG、PWM
- 控制算法：角度环、速度环、方向差速
- 人机交互：OLED、串口地面站、Android App
- 工程流程：CubeMX、Keil、烧录、上板测试、APK 打包、GitHub 归档

第一阶段停止在这里是合理的。后续继续调参、做速度档位和红外循迹，属于第二阶段。
